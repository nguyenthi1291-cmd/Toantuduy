# PROJECT: TIMO 1 — LEARNING & PRACTICE LANDING PAGE

## 1. PROJECT OVERVIEW

Build a modern interactive learning landing page for **TIMO 1 Mathematics**.

The website is designed for young learners preparing for TIMO 1 mathematics competitions.

### Main objectives

The website must help students:
- Learn the core concepts required for TIMO 1.
- Practice through progressively difficult exercises.
- Develop mathematical reasoning and logical thinking.
- Track learning progress.
- Review previously learned topics.
- Build confidence before the competition.

The website should feel like a **fun mathematical learning platform**, not a traditional school textbook.

# 15. LESSON PAGE

Each lesson contains:

## 1. Learning objective
Example:

## 2. Concept explanation
Use:
- Large numbers
- Illustrations
- Number lines
- Objects
- Simple animation

## 3. Worked example
Example:
8 + 5 = ?

Step 1: Start at 8.
Step 2: Count forward 5 steps.
Step 3: Reach 13.

Therefore:
**8 + 5 = 13**

## 4. Try it yourself
Give 3–5 questions.

## 5. Challenge
